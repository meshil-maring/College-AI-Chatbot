# User guide

Step-by-step guides for people who use the College AI Chatbot admin portal.
Each guide explains what a screen is for, the order to do things in, and a
worked example you can follow.

| Guide | Who it is for | What it covers |
| --- | --- | --- |
| [Academic Setup](academic-setup/README.md) | Institution administrators | Departments, programs, the academic calendar, subjects, curricula, batches, sections and student enrollment |
| Student management *(coming soon)* | Institution administrators | Inviting, approving and managing students |
| Staff and faculty management *(coming soon)* | Institution administrators | Inviting staff and faculty, roles and Heads of Department |

## Conventions used in these guides

- **Bold text** is a button, tab or field name exactly as it appears on screen,
  for example **Add Department**.
- *Optional* fields can be left empty and filled in later.
- Each guide uses one example institution, **Greenfield College**, so the
  examples build on each other from page to page.
- Notes marked **Tip** are shortcuts; notes marked **Important** describe a rule
  the system enforces and cannot be bypassed.
