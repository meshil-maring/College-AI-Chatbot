# Maintained migration sources

The approved academic domain removal uses focused, ordered SQL fragments
in [academic_decommission/](academic_decommission/README.md), assembled by
`scripts/maintenance/migrations/build_academic_decommission.py` into the flat
`supabase/migrations/` directory required by Supabase migration discovery.

Edit the sources and regenerate the output. The generated migration has an
explicit generator header and per-fragment hashes; generated output is outside
the maintained source size/count limits. Existing historical migrations retain
their original paths and bytes; this convention does not rewrite applied files.

[membership_approval/](membership_approval/README.md) repairs deployed staff and
faculty approval/rejection contracts without installing the B05 invitation draft.
Generate it with `scripts/maintenance/migrations/build_membership_approval.py`.

Fragments must contain at most 250 physical lines, and each source folder at
most 15 directly contained maintained files. Use meaningful responsibility
subfolders as needed. The manifest lists dependency order explicitly.

The generator owns the outer BEGIN/COMMIT and schema-cache notification. SQL
function bodies may contain their normal procedural blocks. A separate reviewed
deployment step applies the generated migration after local validation.

Replacement Academic Setup sources are separate from the historical removal:

- [academic_foundations/](academic_foundations/README.md) defines departments,
  degree programs and academic years, generated by
  `scripts/maintenance/migrations/build_academic_foundations.py`.
- [academic_structure/](academic_structure/README.md) adds program/year study
  semesters and department-owned reusable subjects, generated by
  `scripts/maintenance/migrations/build_academic_structure.py`.
- [academic_sections/](academic_sections/README.md) adds class-level sections and
  their reusable-subject links, generated by
  `scripts/maintenance/migrations/build_academic_sections.py`.

These generators only assemble source files. Neither generation nor the source
contract tests apply SQL or verify PostgreSQL or production compatibility.

The owner selected the [supplied export](../../academic_state_check_latest.sql) on
2026-10-26. [academic_export/](academic_export/README.md), generated by
`scripts/maintenance/migrations/build_academic_export.py`, supersedes the earlier
setup model through a forward migration. It preserves previous setup data in a
private schema and carries common foundation IDs into the exported model.
[Disposable PostgreSQL validation](../../scripts/validation/academic_export/README.md)
covers replay, rollback, preservation, RPC behavior and privileges.

[academic_workspace/](academic_workspace/README.md) adds versioned curricula,
program progression, admission cohorts, class sections and subject offerings
without replacing the export-aligned tables or APIs. Its generator is
`scripts/maintenance/migrations/build_academic_workspace.py`.
